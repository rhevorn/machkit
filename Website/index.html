Keep your Mac understandable.

MachKit is a free, open-source Mac cleanup and utility app for storage, app removal, system monitoring, networking, annotated screenshots, and 19 practical local tools. The project is sometimes searched for as Mackit or Mach Kit.

A focused tool for each part of your Mac

  • Understand storage health, folder sizes, CPU, memory pressure, and active network state.
  • Clean caches and leftovers with visible explanations and conservative defaults.
  • Uninstall apps with selected related support files and command-line tool guidance.
  • Inspect traffic, connections, listening ports, routes, VPN/TUN, proxies, login items, background tasks, and extensions.
  • Capture any screen region from a global shortcut, annotate with shapes, arrows, highlight, mosaic, and text, then copy or save locally.
  • Use a growing collection of local utilities for text, data, images, networking, diagnostics, and everyday tasks.

Everything runs locally. Supported cleanup and uninstall operations normally move selected files to Trash.
